# TheDAO Round 2 funding timeline

Interactive, stakeholder-aware explanation of TheDAO Security Fund's four-phase Round 2 funding process.

Visitors can follow the general process or focus on the actions, resources, and expected value for security researchers and RFP co-creators.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The `main` branch is deployed automatically to GitHub Pages.
